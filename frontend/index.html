10% Requirement & Design

System Architecture

Full-stack decoupled architecture: Semantic HTML/CSS/JS presentation layer communicating over REST API to Django REST Framework backend with persistent SQLite database engine.

20% Frontend UI & Validation

Human-Centered Design

Crafted with a warm academic mood board and native system typography. Features instant search, multi-faceted filtering, sorting, responsive desktop/mobile layouts, and dual-layer validation.

20% Backend & REST API

Django REST Framework

Class-based StudentViewSet implementing full REST specification with serialization, field-level validators, regex checks, and relational query filters.

20% CRUD Functionality

All 4 Operations Verified

Create via modal with validation, Read via searchable/filterable registry, Update with pre-populated form, Delete with safety verification.

10% Database & Integrity

SQLite with Constraints

Primary keys, unique indexing on student_id and email, NOT NULL constraints, range checks (GPA 0.00-4.00), and automated Django migrations.

10% Automated Testing

14 Automated Tests

100% passing test suite in students/tests.py covering valid creation, duplicate detection, range enforcement, single/bulk retrieval, partial updates, and deletion.
